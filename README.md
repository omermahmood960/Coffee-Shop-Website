## ABOUT THE PROJECT
-----------------
A responsive website for a coffee shop built to showcase our menu, the story of the shop and our Contact Information.
The aim of this project is to practice front end development tools and create a clean user friendly and responsive site 
on both mobile and desktop views

## Features
- Responsive design that works on mobile, tablet, and desktop
- Home page with hero banner and featured items
- Menu section with coffee, drinks, and snacks
- About Us section
- Contact form / location details
- Smooth navigation between sections
- [Add any other feature, e.g. cart, gallery, reservations]

## **TECHNOLOGIES USED**
- **HTML5**
- **CSS3** (Flexbox / Grid)
- **JavaScript**
