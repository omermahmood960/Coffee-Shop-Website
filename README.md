ABOUT THE PROJECT
-----------------
A responsive website for a coffee shop built to showcase our menu, the story of the shop and our Contact Information.
The aim of this project is to practice front end development tools and create a clean user friendly and responsive site 
on both mobile and desktop views

FEATURES
--------
Home Page with Coffee Cup Banner
About Us Section
Menu Section which shows our products like hot coffee, cold coffee
Contact Us Section

**** Technologies Stack
HTML5
CSS3
Javascript
Swiper Slider
